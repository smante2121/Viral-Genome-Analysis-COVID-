Output aligned.sam

Convert SAM → BAM
samtools view -S -b aligned.sam > aligned.bam
Created align.bam

Sort the BAM file
Required for: mpileup, variant calling indexing, IGV visualization
samtools sort aligned.bam -o aligned.sorted.bam
Output: aligned.sorted.bam
Index the sorted BAM
The index lets mpileup and bcftools jump anywhere in the genome.
samtools index aligned.sorted.bam
Output: aligned.sorted.bam.bai


Coverage analysis:
samtools depth aligned.sorted.bam > depth.txt
for plotting coverage later, not required for variant calling

Use BCFtools mpileup (Correct Method on macOS)
Command
bcftools mpileup -f sarscov2_reference.fasta aligned.sorted.bam -Ob -o raw.bcf
Outputs
raw.bcf (binary pileup file)
What we did & Why
BCFtools mpileup is the modern and recommended variant-calling pipeline.
Produces a proper BCF file compatible with bcftools call.
Avoids macOS-related issues with samtools mpileup.
Purpose:
This is the updated version of the mpileup → call pipeline taught in the variant-calling portion of the course.

Variant Calling
Command
bcftools call -mv -Ob -o variants_raw.bcf raw.bcf
bcftools view variants_raw.bcf > variants_raw.vcf
Outputs
variants_raw.bcf (binary variant calls)
variants_raw.vcf (human-readable variant list)
What we did & Why
bcftools call identifies:
SNPs
Indels
Genotypes (GT: 1/1, 0/1)
Allelic depths (AD)
Quality scores (QUAL)
Depth (DP)
Conversion to VCF enables plotting, filtering, and interpretation.
Purpose:
This step directly matches the class content on variant calling, VCF structure, and downstream annotation.




FILTER VARIANTS
bcftools filter -i 'DP>=10 && QUAL>=30' variants_raw.vcf > variants_filtered.vcf
This removes junk and low-quality variants.
filters variants based on exactly the two metrics, depth DH and QUAl vairnet score quality. DP>=10 keeps only variants supported by at least 10 reads. This removes “fake” variants from low-coverage areas. QUAL>=30. keeps only variants with a Phred-scaled confidence score ≥ 30
(meaning 99.9% probability the variant is real).
Output: variants_filtered.vcf which includes: Only real mutations, High-confidence SNPs and indels, Mutations appropriate for your Python analysis
